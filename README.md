# Telegram-бот фотографа

Бот на [aiogram 3](https://docs.aiogram.dev/) для просмотра референсов, бронирования фотосессий и обратной связи.

## Возможности

- Регистрация пользователей при `/start`
- Просмотр референсов по типам фотосессий (студия, улица, питомцы, торжества)
- Бронирование даты и времени через inline-календарь
- Перенос и отмена своих броней
- Просмотр стоимости и отправка вопросов администратору

## Быстрый старт

```bash
cd photo_tg-bot
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
copy .env.example .env        # укажите BOT_TOKEN
python main.py
```

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|--------------|----------|
| `BOT_TOKEN` | да | Токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_CHAT_ID` | нет | ID чата для уведомлений о вопросах пользователей |
| `DB_PATH` | нет | Путь к SQLite (по умолчанию `bot_database.db`) |

## Структура проекта

```
photo_tg-bot/
├── main.py              # Точка входа
├── config.py            # Конфигурация из .env
├── constants.py         # Константы (типы, слоты, статусы)
├── database.py          # SQLite-слой
├── handlers/            # Обработчики Telegram-событий
├── keyboards/           # Клавиатуры
├── services/            # Бизнес-логика бронирования
├── states/              # FSM-состояния
└── tests/               # Unit-тесты
```

## Тесты

```bash
pip install -r requirements.txt
pytest -v
```

## Команды бота
- `/admin` — вход в админку
- `/start` — регистрация и главное меню
- `/cancel` — отмена текущего действия (например, ввода вопроса)

## Безопасность

- Не коммитьте файл `.env` и токены в репозиторий
- Если токен был в коде ранее — **обязательно ротируйте** его в BotFather
